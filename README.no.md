# redbeardvfx

[English](README.md) · Norsk

Portefølje for Rustam Masuev – VFX supervisor og compositor. Kundeprosjekt.

React 19, TypeScript, Vite, SCSS-moduler, Feature-Sliced Design. Kontaktskjemaet er en Vercel-funksjon i `api/`, sender via Resend.

## Kjør

```bash
npm install
npm run dev
npm test
```

Skjemaet trenger `RESEND_API_KEY` og `RESEND_TO_EMAIL` i Vercel eller lokal `.env`.
